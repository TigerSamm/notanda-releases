## About Notanda

Notanda is a practice management application designed for therapists, psychologists and coaches.

Manage clients, organise sessions, securely record notes and streamline your practice from one desktop application, with privacy at its core.

## Updates

New versions are published through GitHub Releases. Each release may include new features, improvements, security updates and bug fixes.
